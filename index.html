01 · PROTECT

Make the watermark part of the photo,
not an afterthought.

Add text or a logo and tune the font, color, size, opacity and position to suit the image. Process up to 12 photos at once, adjust placement per photo, and reuse saved designs. Applying a visible watermark also inserts the invisible SIGNA signal in the same flow.

Text or logo · Up to 12 photos · Per-photo placement · Saved designs · Pro downloadable fonts · SIGNA signal in the same flow
How should you watermark a photo before sharing? →
02 · PROTECT

Prepare the photo
without covering it.

When you do not want text or a logo on top of the image, add only the invisible SIGNA signal. Choose Original for a reference copy or SNS for a share-ready copy, and process up to 9 photos at once. Later, SIGNA Inspect can read the signal and compare it with a local insertion record when one exists on that device.

Original or SNS · Up to 9 photos · Optional certification key · Local insertion record · Inspect later in SIGNA
How does an invisible signal fit into a sharing workflow? →
03 · INSPECT

Signal, file information and image state,
in one place.

SIGNA Inspect organizes the SIGNA signal, file/EXIF information, image-state clues and Content Credentials information when present. If the same device has a matching insertion record, that relationship is shown alongside the file information.

SIGNA signal · File/EXIF · Image state · Content Credentials when present · Local record match

DOCUMENT IMAGES · INVISIBLE SIGNAL

Sharing a document as JPG or PNG?

When a visible watermark would get in the way, you can add an invisible SIGNA signal to a supported document image before sending it. The page stays readable, and the image can be checked again later in SIGNA.

Useful for quotes, confirmations and other image-based documents · Keeps the page visually clear · Works with supported JPG/PNG image workflows

SUPPORTED PHOTO PROCESSING ON-DEVICE

Work with the photo
on your Android device.

Supported watermarking, SIGNA signal inspection and image-state review run on the Android device without requiring that photo to be uploaded to a SIGNA server for that processing. That is useful for client images, family photos and work that is not ready to be shared publicly.
