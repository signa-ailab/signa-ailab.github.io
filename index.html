03 · IMAGE ANALYSIS

Look beyond the picture

Open the file in SIGNA Inspect to check its details and EXIF metadata, look for a SIGNA signal, and see clues about how the image was processed. If the device has a matching record of when the signal was added, you can see that too. You can check JPEG compression settings and save image analysis maps to your gallery.

SIGNA signal · File details and EXIF · Image condition

See what a JPEG’s Content Credentials say

If a JPEG contains Content Credentials (C2PA), you can see whether its signature checks out and whether the signer was recognized on the trust list. The record can also show the tool used, how the image was made, and a signing time when verified.
