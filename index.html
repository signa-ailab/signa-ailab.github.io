01 · PROTECT

A watermark that works with the photo,
not against it.

The Designer gives portrait and landscape photos their own editing workspace. Set up a text or logo watermark with the typeface, color, scale, opacity and placement you want. The core tools are free: edit up to 12 photos in one session, adjust placement on each and save a design for later. Pro offers additional downloadable fonts. An invisible SIGNA signal is added alongside the visible mark only if you switch that option on.

Free watermark tools · Portrait and landscape layouts · Up to 12 photos · Individual placement · Saved designs · Extra Pro fonts
How should you watermark a photo before sharing? →
02 · PROTECT

Want the photo clear of words and logos?

Add only the invisible SIGNA signal. Choose Original when preparing a reference copy or SNS for a sharing copy, and process up to nine photos at a time. SIGNA Inspect can look for the signal in the file later; if a matching insertion record is still stored in the app on that device, it can show that separately.

Original or SNS · Up to 9 photos · Optional certification key · Local insertion record · Inspect later in SIGNA
How does an invisible signal fit into a sharing workflow? →
03 · INSPECT

See what the file can tell you.

SIGNA Inspect groups the available SIGNA signal, file and EXIF details, image-state clues and Content Credentials information. A matching local insertion record is shown as a separate relationship when it exists on the current device.

SIGNA signal · File/EXIF · Image state · Content Credentials when present · Local record match

04 · REPORT

Keep the findings where you can find them.

Pro Evidence Report gathers the observations and their context into a local report. Save it, revisit it or export a copy whenever you need it.

  • SIGNA signal and local insertion-record context
  • File/EXIF, image-state and Content Credentials information when available
  • A saved report you can return to or export
DOCUMENT IMAGES · INVISIBLE SIGNAL

Sending a quote or confirmation as an image?

When a visible watermark would obscure the text, add an invisible SIGNA signal to a supported JPG or PNG document image instead. You can keep the page clear to read and inspect that image in SIGNA later.

Useful for quotes, confirmations and other image-based documents · Keeps the page visually clear · Works with supported JPG/PNG image workflows
