# SIGNA AI Lab

This repository powers the official website of **SIGNA AI Lab**.

**SIGNA AI Lab develops SIGNA**, an Android app for visible watermarks, invisible SIGNA signals, and on-device image review.

- Official website: https://signa-ailab.github.io/
- Google Play: https://play.google.com/store/apps/details?id=com.signa.app
- Naver Blog: https://blog.naver.com/signaailab
- Instagram: https://www.instagram.com/signa.ailab/

**SIGNA** is the product name. **SIGNA AI Lab** is the developer brand used across the official website and public channels.
