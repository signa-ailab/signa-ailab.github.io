Vor dem Veröffentlichen: Erst das Ziel des Wasserzeichens festlegen

Ein Text eignet sich, wenn Name oder Account direkt sichtbar sein sollen. Ein Logo sorgt für einen einheitlichen Markenauftritt. Ein unsichtbares Signal bildet eine zusätzliche maschinenlesbare Ebene, ohne das Foto zu überdecken. Position, Größe und Transparenz sollten so gewählt werden, dass das Bild selbst im Vordergrund bleibt.

Text, Logo und unsichtbares Signal erfüllen unterschiedliche Aufgaben

Text und Logo vermitteln ihre Botschaft sofort. Ein unsichtbares Signal erfüllt eine andere Aufgabe: Es ergänzt vor dem Teilen eine zusätzliche Ebene, ohne das Foto zu überdecken, und kann später in einem unterstützten Prüfablauf wieder gesucht werden.

Invisible watermark: how it works and what can break it

Eine eigene Version zum Teilen vorbereiten

Bewahren Sie das Original auf und erstellen Sie bei Bedarf eine Version zum Veröffentlichen. Prüfen Sie sichtbare private Details und verfügbare Metadaten, fügen Sie die gewünschten Ebenen hinzu und kontrollieren Sie anschließend den Export. Bei mehreren Fotos hilft die Stapelverarbeitung, Einstellungen einheitlich zu halten.

Check photo privacy before sharing

Nach dem Teilen kann sich das Bild verändern

Soziale Netzwerke und Messenger können Fotos neu komprimieren, skalieren, zuschneiden oder anderweitig verarbeiten. Ein sichtbares Wasserzeichen kann danach anders aussehen, und ein unsichtbares Signal kann schwerer wiederzufinden sein.
