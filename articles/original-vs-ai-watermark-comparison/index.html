AI IMAGE COMPARISON · WATERMARKS

Which photo is the original? We compared a visible watermark, AI removal and an AI-made lookalike

The four images below share the same scene, but they do not share the same history. One is the source photo, one carries a visible watermark, one was edited by AI to remove that mark, and one was generated anew to resemble the scene. Try the comparison before opening the answer.

October 7, 2026 · SIGNA AI Lab
What this comparison is for
  • See how four images can look related while coming from very different workflows.
  • Separate a visible watermark, an AI edit, a newly generated lookalike and the source photo.
  • Understand why “looks the same” is a weak substitute for a repeatable pre-share and review workflow.

Start with your eyes: which one is the original?

Look at A through D in order. Do not zoom into metadata or file properties yet. The point of the first pass is simply to notice how quickly visual confidence can become shaky when the scene, composition and lighting are similar.

For web display, the four files are shown at the same dimensions. This is a visual comparison of known creation paths, not a detector benchmark and not a metadata-forensics test.

Show the answer and how each file was made

A is the source photo with a visible “SIGNA AI Lab” watermark added. B is an AI-edited result made from the watermarked version with the visible mark removed. C was generated as a new image using the source scene only as a visual reference rather than editing the source file. D is the source photo used for the comparison.

The important distinction is workflow: B is an edited derivative, C is a newly generated lookalike, and D is the source file. A polished appearance does not erase those differences.

The first lesson: removing a watermark is not the same as recovering the pixels underneath

When an AI editing tool removes a visible mark, it has to produce plausible replacement pixels for the covered area. It is not revealing the exact untouched pixels that were covered by the mark. In this example, the AI-edited result also shifts parts of the overall color, contrast and fine texture. That is useful to notice because “the watermark is gone” describes only one visible outcome, not the full edit history.

This is one reason visible watermarks still have a practical role. They make attribution or branding obvious to a human viewer and add friction to casual reuse. The right conclusion is not that visible marks are pointless; it is that one visible element should not be expected to carry every job after a file leaves your device.

A newly generated lookalike is a different problem again

Image C was not made by erasing the mark from the source. It was generated anew to resemble the scene. The skyline, cherry blossoms, warm evening light and lake are recognizable, but the small geometry of buildings, branch patterns, reflections and texture are not a pixel-for-pixel continuation of the original.

That distinction matters. A derivative edit and a newly generated imitation can both feel “close” in a feed, yet they come from different creation paths. Visual similarity alone cannot tell you the whole path that produced the file in front of you.

Visible mark
Useful for immediate attribution and branding. It is a human-readable signal, not the whole history of the file.
AI removal
Produces a new edited result by reconstructing visible pixels. The result should be treated as another derivative file.
AI recreation
Creates a separate image that can resemble the reference while changing structural details throughout the scene.
Source photo
The starting file in this controlled comparison. We know its role because we created the test set, not because a visual detector inferred it.

What can you actually learn by looking closely?

Visual inspection is still useful. It can tell you where to look next. Repeating textures, branch shapes, building edges, typography, reflections and small perspective relationships can reveal differences between versions. In this set, the AI-generated and AI-edited images also carry a warmer, more reconstructed look than the source.

But visual anomalies are leads, not verdicts. Compression, HDR, sharpening, resizing and ordinary editing can also change local texture. A professional review separates observation from interpretation: first describe what differs, then ask which workflow could plausibly explain it.

For creators, the more useful question comes before upload

If the image may be reposted, edited or stripped of a visible mark, the practical move is to prepare the sharing copy before it leaves your device. Keep the source file separately. Use a visible text or logo watermark when you want people to see the attribution immediately. If you want a less intrusive technical reference as well, add an invisible SIGNA signal to the sharing copy.

The takeaway is not “trust nothing”

The useful conclusion is more practical: keep your reference file, prepare a sharing copy deliberately, and review returned files with more than one kind of information. A visible watermark helps people understand attribution at a glance. An invisible signal answers a narrower technical question. File/EXIF data, image-state observations and Content Credentials each add different context.
